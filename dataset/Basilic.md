# Résumé
Herbe aromatique incontournable en cuisine méditerranéenne.

# Culture
- Semis dès 18 °C.  
- Sol riche, drainé.  
- Exposition plein soleil.  

# Entretien
- Arrosages réguliers.  
- Pincer les fleurs pour prolonger la récolte.
